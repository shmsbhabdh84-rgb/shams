تقرير شامل عن لغة تنسيق النصوص (CSS)

اسم الطالبة: شمس بهاء عبد الفتاح عبد الوهاب عبدة

الرقم الجامعي: 2500007

1. المقدمة

تُعد لغة CSS (Cascading Style Sheets) الركيزة الأساسية لتصميم وتنسيق صفحات الويب. بينما تهتم لغة HTML ببناء هيكل الصفحة، تأتي CSS لتمنحها الجمالية والألوان والتخطيط المناسب، مما يتيح للمطورين فصل محتوى الصفحة عن تصميمها لضمان تجربة مستخدم متميزة ومتجاوبة مع مختلف الأجهزة.

2. عرض الموضوع

تتميز لغة CSS بقدرتها الفائقة على التحكم في مظهر العناصر على الشاشة. فهي تتيح التحكم في الخطوط، الألوان، الهوامش، وتوزيع العناصر (Layout) بطرق متقدمة مثل Flexbox و Grid.
